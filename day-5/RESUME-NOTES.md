## ⚡ 3. When You Turn Your EC2 Instance Back On

Run these quick 3 steps after booting up:

### Step 1: Ensure Kind cluster containers are running
```bash
docker ps
```
*(If the Kind containers aren't running, start them with: `docker start two-node-cluster-control-plane two-node-cluster-worker`)*

### Step 2: Check all logging pods
```bash
kubectl get pods -n logging
```
*(Give it ~1-2 minutes for the JVM and Kibana plugins to initialize)*

### Step 3: Launch Kibana Port Forwarding
```bash
kubectl port-forward svc/kibana-kibana 5601:5601 --address 0.0.0.0 -n logging &
```
*(Then open `http://localhost:5601` in your browser)*
