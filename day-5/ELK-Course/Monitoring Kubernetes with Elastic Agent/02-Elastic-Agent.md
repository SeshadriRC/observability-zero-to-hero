With Elastic Agent you can collect all forms of data from anywhere with a single unified agent per host. One thing to install, configure, and scale.

In this challenge you will follow the Kibana quickstart and learn how to use the Elastic Agent to collect logs and metrics from your Kubernetes environment.

1. Click Add data at the bottom of the Kibana main menu.

<img width="2664" height="1504" alt="image" src="https://github.com/user-attachments/assets/08df3803-b69e-4a67-b839-67ed086837d5" />

2. Select Kubernetes.

<img width="2008" height="812" alt="image" src="https://github.com/user-attachments/assets/efd1e229-430f-491e-8aa1-a87f2ac448be" />

3. And select Elastic Agent: Logs & Metrics to start collecting logs and metrics with the Elastic Agent.

<img width="1356" height="600" alt="image" src="https://github.com/user-attachments/assets/0909606d-ad29-40a7-b6db-4108f45d9015" />

4. The first step is to install the standalone Elastic Agent on your Kubernetes cluster. Copy the command line shown in Kibana to the clipboard and use it in the next step.

<img width="2012" height="806" alt="image" src="https://github.com/user-attachments/assets/da6b56c1-c0a5-481d-a805-49e72e9b0dcf" />

5. Switch to the Terminal tab, paste and run the command you copied.

6. Next, go back to Kibana and wait until data to be shipped, so you can start monitoring your Kubernetes cluster.\

<img width="1148" height="593" alt="image" src="https://github.com/user-attachments/assets/a99634a7-8970-4a8d-8d6d-7c66fe62479f" />

<img width="1412" height="708" alt="image" src="https://github.com/user-attachments/assets/3ea23b59-93dd-4ff4-a2d5-1944a1676b37" />

7. Now, you can start visualizing the data being collected, which you will be doing in the next challenges.
